# Game Design Index

The game design is organized by roadmap item under [`docs/design/`](design/README.md). This file is intentionally short so a session can discover the relevant brief without loading the original 96 KB discovery document.

## Reading contract

1. Read [`ROADMAP.md`](ROADMAP.md) and [`CURRENT_STATE.md`](CURRENT_STATE.md).
2. Open only the design brief linked for the active roadmap item in [`design/README.md`](design/README.md).
3. Read a dependency brief only when the active brief names it under **Read with**.
4. Consult [`DECISIONS.md`](DECISIONS.md) for the concise accepted-decision index.
5. Use [`design/archive/INITIAL_GAME_BRIEF.md`](design/archive/INITIAL_GAME_BRIEF.md) only for historical research or provenance that the focused briefs do not cover.

New accepted design details belong in the active roadmap item's brief. Cross-cutting decisions should also be summarized in `DECISIONS.md` and linked from every affected brief rather than copied in full.
