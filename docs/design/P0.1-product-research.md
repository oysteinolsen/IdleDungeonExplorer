# P0.1 — Product Research

Status: **DONE**

This item established the market and platform evidence behind the accepted direction. No implementation item needs to load the full research by default.

## Findings carried forward

- Melvor Idle's durable pattern is a network of simple repeating actions, skill unlocks, interconnected production, shared online/offline rules, and overlapping collection goals.
- Roblox requires mobile-first presentation, an immediately understandable first action, visible ownership/status, contextual onboarding, social presence, and strong feedback.
- The closest thematic competitor, *The Forge*, emphasizes active Mining/Forging/Fighting. This project differentiates itself through idle professions, authored dungeon sequences, active first clears followed by risk-bearing repeat simulation, unsecured loot, and a broader profession network.
- Low-chance rewards must sit on dependable progress. Sources and odds should be visible where practical, and progression-critical drops should eventually have a non-random fallback.
- The public brand must represent an expandable profession RPG rather than only Mining or Forging. The final invented name remains deferred and should use the subtitle **Idle RPG**.
