# P2.1 — Continuous Mining

Status: **DONE**

**Read with:** [`P1.4-profession-progression.md`](P1.4-profession-progression.md).

- One interaction at a visible ore node starts continuous Mining; holding, autoclicking, and weak-spot input are not required.
- The player must own/select an eligible pickaxe. The avatar shows it and repeats swings with progress and reward feedback.
- The server owns start/stop validation, timestamps, completed cycles, ore, and XP. The client predicts only presentation and reconciles from snapshots.
- Mining repeats until stopped, the player leaves the allowed area, changes activity, or no longer satisfies a requirement.
- The same action definition and modifier pipeline drive online and offline progress.
- P2.1 uses one level-1 ore and an owned starter-pickaxe fixture. P2.2 replaces the fixture with the accepted Gold purchase and handles bank capacity/overflow.

Future spatial node connection must not weaken the existing server-authoritative command boundary.
