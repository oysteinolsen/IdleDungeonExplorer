# P2.2 — Bank and Economy

Status: **IMPLEMENTED — MANUAL PLAYTEST PENDING**

**Read with:** [`P1.4-profession-progression.md`](P1.4-profession-progression.md) and [`P2.1-mining.md`](P2.1-mining.md).

## Shared bank

- Start with 40 shared slots. A distinct stack consumes one slot; tabs organize All, Materials, Equipment, Consumables, and Special but do not add capacity.
- Identical resources stack. Deterministic equipment may stack only when complete identity matches; unique/affixed instances occupy separate slots.
- Manual transfers fail safely when full. Favorites protect items from accidental selling or destructive selection.
- Permanent `+1 Bank Slot` upgrades cost Gold on a data-configured increasing curve. Do not sell bank slots for Robux in the first version.

## Mining overflow

When a completed Mining reward cannot fit, discard only the item reward. Mining and profession XP continue. Show a persistent warning and changed reward feedback, include overflow in return reports, and record overflow counts. Never silently replace another item.

## Selling, Gold, and tools

Ore, bars, equipment, and selected monster materials can be sold. Gold sinks include consumables, bank slots, profession tools, later facilities, equipment upgrades, and earned convenience. Avoid routine durability/repair taxes and ordinary dungeon entry fees.

New accounts have 100 Gold. The 50-Gold starter pickaxe and later level-gated upgrades are permanent tool unlocks. Purchases and selling are server-authoritative atomic transactions with explicit failures and idempotency tests.

## Prototype implementation details

- `prototype.v3` adds a 2-Gold Copper Ore sell value, the permanent 50-Gold level-1 Starter Pickaxe, and a permanent 250-Gold level-10 Copper Pickaxe. The upgrade requires the starter tier and reduces the base 3-second Copper action to 2.25 seconds; Mining automatically selects the highest owned level-eligible pickaxe.
- Fresh session profiles now use player-data schema v2, start with 100 Gold and no owned tool, and store 128 bounded recent economy transaction receipts. Exact successful retries do not apply twice, while reuse of an ID for another operation fails explicitly.
- The first bank-slot upgrade costs 200 Gold. Each subsequent `+1` slot costs 50 Gold more, up to a prototype maximum of 200 slots. This is versioned as `economy_balance.v1`.
- The responsive economy panel exposes the five accepted bank views (All, Materials, Gear, Use, and Special), safe favorite toggles, Sell 1/Sell All, tool offers, and the next bank-slot price. After the first device playtest exposed clipping on a short mobile viewport, it was changed to a higher-layer modal centered inside `CoreUISafeInsets`, with 12-pixel responsive margins, no minimum size that can force overflow, a bounded desktop maximum, selectable 48-pixel controls, an outside-tap scrim, and vertically scrolling content. A follow-up empty-modal report exposed ambiguous descendant layering; the screen now uses explicit global layers for the scrim, panel, static controls, dynamic rows, text, and buttons.
- The repository now owns a first polished icon set for Copper Ore, the Starter Pickaxe, and the Copper Pickaxe under `assets/icons/`. Essential names, quantities, prices, and requirements remain visible for accessibility, but the final bank/tool rows should lead with artwork rather than text alone. Roblox image asset IDs are intentionally not invented: the transparent PNGs require one authorized Studio/Creator Dashboard import before runtime wiring.
- Mining uses the shared bank transaction boundary. A matching stack accepts rewards even when all distinct slots are occupied; a new stack that cannot fit is discarded without replacing anything. XP and action timing still commit, while the Mining snapshot, persistent warning, session statistic, and event record distinguish banked and overflow quantities.
