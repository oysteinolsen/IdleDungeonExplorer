# P3.1 — Repeating Forging

Status: **PLANNED**

**Read with:** [`P1.3-content-domain.md`](P1.3-content-domain.md) and [`P1.4-profession-progression.md`](P1.4-profession-progression.md).

- Forging contains smelting and forging; Crafting remains a future profession.
- Select a recipe and quantity, including repeat-until-stopped, then start once. The station animation and progress repeat automatically.
- Reserve ingredients for one item atomically and persist that reservation in the active-action snapshot.
- Completion consumes the reservation and grants output/XP as one transaction. Deliberate abort discards unfinished progress and returns that item's reservation; completed items remain earned.
- Stop when quantity completes, ingredients run out, output cannot fit, or the player aborts. Explicitly surface each stop reason.
- No mandatory rhythm/timing minigame. Active interaction may add feedback later without changing unattended production as the normal mode.
