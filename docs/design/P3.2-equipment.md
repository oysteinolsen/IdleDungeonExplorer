# P3.2 — Equipment

Status: **PLANNED**

**Read with:** [`P1.3-content-domain.md`](P1.3-content-domain.md) and [`P3.1-forging.md`](P3.1-forging.md).

- Prototype content adds one representative bar, weapon, armour item, equipment stats, and visible weapon/helmet attachments.
- Weapons expose Damage, attack type, and interval; armour exposes Defence/Resistance and slot identity. Prototype items use deterministic base stats.
- Launch slots are Weapon, Shield, Head, Chest, Legs, Feet, Hands, Amulet, and Ring. Slots are registry definitions, and loadouts map stable slot IDs to items.
- Each slot declares order/group, accepted tags, quantity rules, incompatibilities, style restrictions, and death-loss eligibility. New slots default empty; removing/renaming one requires a migration that returns items safely.
- Item templates use stable IDs and individual instances use unique IDs so later affixes, upgrades, and permanent loss are representable.
- Private visuals prioritize held pickaxe/weapon, shield, and rigid helmet. Other slots remain functional in stats/UI without requiring fitted full-body models.
- Prefix/suffix definitions and generated identities remain supported by the data model but are not enabled in the prototype.
