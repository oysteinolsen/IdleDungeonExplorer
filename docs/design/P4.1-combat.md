# P4.1 — Combat Foundation

Status: **PLANNED**

**Read with:** [`P3.2-equipment.md`](P3.2-equipment.md).

- Combat is one player against one predetermined monster at a time. Basic attacks repeat from attack interval.
- Prototype active choices are movement away from telegraphed danger, Power Strike, food/potion use, and the decision to bank or leave. There are no combos, stamina, manual basic-attack timing, parries, or complex hotbars.
- Power Strike is a readable cooldown attack with increased weapon damage. Active play triggers it manually; automatic/offline combat uses the same ability-priority rule.
- The deterministic server simulator owns timing, accuracy, damage, resistance, healing thresholds, supply use, abilities, and monster mechanics. Active presentation and offline resolution call the same domain rules.
- Support Melee, Ranged, and Magic in the model, with the triangle expressed as configuration. The prototype exposes only Melee players/enemies, so all current matchups are neutral.
- Supplies, random inputs/seeds, and outcomes must be explicit enough for reproducible tests and later balance-workbench scenarios.
