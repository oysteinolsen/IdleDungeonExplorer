## Encounters and first-clear gate

- A dungeon definition lists ordered encounters or controlled pools, counts, boss, requirements, first-clear reward, repeat loot, and offline eligibility.
- The first underground cave/burrow dungeon uses rats and snakes and ends with the Rat King.
- The Rat King crouches and draws both claws back before a straight two-claw lunge. Active players can sidestep the telegraphed lane; simulation resolves the same move through configured rules.
- First clear requires active play in a compact 3D room. Success unlocks automatic online and offline repetition. An explicit repeat toggle controls whether another run starts.

## Configurable loot

Dungeon code references versioned server loot tables; it contains no item-specific reward branches. Entries declare stable item/nested-table IDs, context, weights/probability, quantities, rolls, conditions, unique/fallback behavior, and analytics labels. Ordinary inventory loot remains repeatable; collection discovery never removes an item from future rolls.

Drops enter the 16-entry unsecured container. Stackables merge and equipment occupies individual entries. Online players may bank at any time. Offline loot waits unsecured for the return report. If the container fills, combat stops safely; successful completion never secures loot automatically.

The rare Auto-Loot Ring can transfer drops to the bank when space exists. It occupies a Ring slot, remains repeatable loot, and is eligible for death loss. If bank and unsecured container are both full, stop safely.
