# P4.3 — Death and Loss

Status: **PLANNED**

**Read with:** [`P4.1-combat.md`](P4.1-combat.md), [`P4.2-dungeon.md`](P4.2-dungeon.md), and [`P3.2-equipment.md`](P3.2-equipment.md).

On death:

- keep earned XP and previously secured inventory;
- keep supplies consumed as consumed;
- stop the run at the calculated death time;
- lose all unsecured dungeon loot;
- permanently destroy one randomly selected eligible equipped weapon or armour item;
- never select food, potions, cosmetics, pets, profession tools, entitlements, or banked/non-equipped items.

Offline combat uses the same rule. Never generate rewards after death. The return report explains the encounter, supplies consumed, unsecured loot lost, and destroyed equipment.

The UI exposes understandable player/enemy information and known mechanics but never claims a build is completely safe to idle. Enabling offline combat requires an explicit risk warning. Any later item-protection mechanic requires a separate decision and must not be a death-screen Robux sale.

Transaction tests must cover empty/no-eligible equipment pools, deterministic seeded selection, atomic loss, save/retry behavior, and no duplicate destruction.
