# P5.2 — Offline Simulation

Status: **PLANNED**

**Read with:** [`P5.1-persistence.md`](P5.1-persistence.md) and the active system brief (`P2.1`, `P3.1`, or `P4.1`–`P4.3`).

Compute `effectiveElapsedTime = min(realElapsedTime, 24 hours) × offlineEfficiency`, then run the normal deterministic action or combat simulator. Efficiency starts at 50%; later earned Gold/milestone upgrades may raise it to a non-paid ceiling of 75%.

- Mining uses the same selected ore/tool, grants XP after bank overflow, and discards only item outputs that cannot fit.
- Forging stops when inputs run out or output cannot fit and preserves the atomic current-item reservation rules.
- Dungeon simulation uses real attacks, supplies, encounter order, special moves, repeat setting, unsecured-loot limits, and death loss. It may stop far earlier than 24 hours.
- Validate timestamps and caps on the server. Do not simulate avatar movement or invent separate offline reward tables.
- The return report states effective time, actions/runs completed, rewards, XP, supplies, overflow, stop reason, unsecured loot, and all death consequences.

Offline efficiency or duration is not sold for Robux in the first version.
