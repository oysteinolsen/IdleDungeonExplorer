# T1.1 — Balance Tool Selection

Status: **PLANNED**

**Read with:** the brief for the system being evaluated.

Explore repository-owned tools first, with spreadsheets or external analytics only when they materially improve iteration. Cover XP-curve visualization, time-to-level projections, resource and Gold flows, tool/interval comparisons, offline outcomes, deterministic combat scenarios, representative player progression, and playtest telemetry analysis.

Selection criteria include reproducible inputs, named content/balance versions, deterministic seeds, reviewable/exportable outputs, low maintenance cost, and reuse of production domain rules rather than duplicated formulas. Record the selected tool boundary and explicitly defer features that are not needed by the private prototype.
