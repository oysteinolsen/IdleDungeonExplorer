# T1.2 — Minimum Balance Workbench

Status: **PLANNED**

**Read with:** [`T1.1-balance-tool-selection.md`](T1.1-balance-tool-selection.md) and the briefs for the systems being simulated.

Build this after the shared scheduler and economy contracts exist. It must run seeded simulations faster than real time, apply named balance/curve versions and explicit test-only XP multipliers, compare online/offline and tool-quality scenarios, and export reproducible review tables.

Initial outputs cover profession thresholds/time projections, resource and Gold sources/sinks, action interval and tool comparisons, bank overflow, offline stop reasons, and deterministic combat outcomes. The workbench calls the same pure domain rules as production and does not become a second gameplay implementation.
